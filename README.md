# Developer Portfolio Starter

A responsive personal portfolio built with HTML and CSS, with a tiny JavaScript snippet for the mobile navigation and current year.

## Open it in VS Code
1. Extract this ZIP file.
2. Open the `developer-portfolio` folder in VS Code.
3. Open `index.html` in your browser (or use the Live Server extension).

## Publish with GitHub Pages
1. Create a GitHub repository named `yourusername.github.io` (replace `yourusername` with your GitHub username).
2. Upload `index.html` and `style.css` to the repository's root.
3. In the repository, open Settings -> Pages.
4. Choose deployment from the `main` branch and the root folder, then save.
5. Wait for GitHub Pages to publish, then open `https://yourusername.github.io`.

Note: This portfolio is a static website. Java is not required to host it on GitHub Pages; GitHub Pages does not run Java backend code.
