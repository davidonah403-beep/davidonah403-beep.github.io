# Onah David — Developer Portfolio (Version 2)

A responsive personal portfolio built with HTML and CSS, with a small JavaScript interaction for the mobile navigation and current year.

## Files
- `index.html` — portfolio content and structure
- `style.css` — responsive styling

## Publish on GitHub Pages
1. Extract this ZIP.
2. Open the extracted folder and select `index.html`, `style.css`, and `README.md`.
3. Upload them to the root of the repository `davidonah403-beep.github.io`.
4. Commit the changes to the `main` branch.
5. GitHub Pages should redeploy automatically.

Live website: https://davidonah403-beep.github.io/
GitHub profile: https://github.com/davidonah403-beep

## Before applying for jobs
- Review every sentence and make sure you can explain it.
- The portfolio currently features the live portfolio website as its confirmed project.
- Add other projects only after you have built and tested them; replace the “More projects are on the way” note with real project details and links.
- The skills are described as areas of focus, not proficiency ratings.
- Do not add experience, qualifications, or projects you cannot demonstrate.
